Easy server hosting

From ZIP to dungeon.

Run a persistent world on your computer. Three steps to get started.

Node.js 22+ required
  1. Install Node.js LTS once

    Get it from nodejs.org ↗. It includes everything the launcher needs.

  2. Download and extract the server

    Keep the extracted folder somewhere permanent. Your heroes and world will live here.

    Download server ZIP ↓
  3. Launch it for your system

    Double-click start-server.cmd in the extracted folder.

    Keep the window open while you play.

    Open a terminal in the extracted folder and run:

    sh start-server.sh

    First launch installs dependencies. Later launches reuse them.

Server running?

Enter your dungeon.

Open http://localhost:3143 in your browser for the one-command client launchers. Or run a downloaded client and connect to:

localhost:3143

Choose Register to create your hero. Once you're in, press P to invite friends.

Bringing friends?
On the same network, share the address printed in the server window. Across the Internet, use a reachable host or forward TCP port 3143 on your router.

Press Ctrl+C to stop. Launch from the same folder next time to keep your world.

Before you descend

A few useful answers.

Read the full guide ↗
Can I play directly in my browser?

The game runs in a terminal client. This website provides downloads and setup instructions. It doesn't host a playable browser version or a public game server.

Can I play alone?

Yes. Start your own server and connect a single client. Add friends whenever you want; parties support up to four players.

Why can't my friend connect?

localhost only works on the computer running the server. Friends on your Wi-Fi or LAN need that computer's LAN address. Friends elsewhere need a reachable public host or TCP port forwarding. Make sure your firewall allows the server on the network you intend to use.

Where are my saves? How do I update?

Heroes are stored in server/users.db and the world in server/utils/map.json. Stop the server and back up both before updating. Keep your saves when replacing the server files, then relaunch. Each server has its own heroes.

Is it free? Can I change the game?

Yes. The project is open source under the MIT license. Host your own world, read the source, or contribute on GitHub. This is early access, so expect bugs and balance changes.
