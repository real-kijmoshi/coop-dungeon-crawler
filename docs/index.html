Launch and join a server
  1. On Windows, open the client in Windows Terminal. On macOS or Linux, replace CLIENT_FILE with the downloaded filename and run chmod +x ./CLIENT_FILE && ./CLIENT_FILE from its folder.
  2. Choose Create a new hero and enter the address from your host. Use localhost:3143 for a local server, or the local address printed by the host.

Windows x64 host

Double-click to start. Node.js is bundled. Choose Cloudflare for a shareable Internet link, or use Direct, Both, LAN, or Local mode.

Server ZIP

For Windows, macOS, and Linux. Install Node.js LTS, extract the ZIP, then double-click start-server.cmd on Windows or run sh start-server.sh on macOS or Linux.

Playing and hosting

Can I play alone?

Yes. Run a server on your computer and connect a single client. Friends can join later.

How do friends connect over the Internet?

On Windows, pick Cloudflare mode and share the HTTPS link printed by the host. The link changes when you restart. In Direct mode, copy the entire invite including #key=…. Friends on the same network can use the LAN address the server prints.

Where are my saves?

The Windows host stores saves in %LOCALAPPDATA%/CoopDungeonHost/saves. Back up the adjacent tls folder to keep your Direct invite identity. The ZIP server stores heroes in server/users.db and the world in server/utils/map.json. Stop the server before backing up saves.

How do client updates work?

Clients with automatic updates check GitHub for newer stable builds on startup. A verified update takes effect the next time you open the client. Launch with -no-update to skip the check.
