      Set up your server →

      Windows: one executable

      Download the host, double-click it and pick a mode. It bundles Node.js and the server, and saves to %LOCALAPPDATA%/CoopDungeonHost/saves.

      1 · CloudflareA full HTTPS address to share. No router setup.
      2 · DirectEncrypted invite with #key=…, router forwarding.
      3 · BothDirect, with Cloudflare as a backup.
      4 · LANFriends on your network.
      5 · LocalJust this computer.
      ⬇ Download Windows host .exe

      Cloudflare needs no admin access or inbound firewall change. The temporary address changes on each restart, and anyone with the URL can reach your game server. Keep the window open; press Enter to save and stop.

      Direct / Both asks permission to open this app's TCP port and tries UPnP/NAT-PMP router forwarding (it never disables your firewall). Share the full invite, including #key=…, in the client's Server field. CGNAT or unsupported routers may need Cloudflare.

      LAN prints local addresses. To add a private-network firewall rule run cdc-host-windows-amd64.exe --lan --open-firewall.

      Before you descend

      Questions by the fire.

      Read the full guide ↗
      Can I play in my browser?

      The game is played in a terminal client. This website has the downloads and setup help. If you run curl <server>/watch you can spectate a server from any terminal without installing anything.

      Can I play alone?

      Yes. Start a server and connect a single client; invite friends whenever you like. Parties hold up to four heroes, and party members share the XP of every kill.

      How long does it take to reach level 100?

      Roughly 15-25 hours of play. The balance was tuned by fast-forwarding AI heroes through the real game engine for thousands of simulated hours, so level 90 is as tense as level 20.

      Why can't my friend connect?

      localhost only works on the computer running the server. Friends on your network need its LAN address; friends elsewhere need the Windows host's Cloudflare or Direct mode, or a reachable public host. Check your firewall allows the server on the network you use.

      Where are my saves? How do I update?

      The Windows host saves in %LOCALAPPDATA%/CoopDungeonHost/saves (direct server identity in the neighbouring tls folder). For ZIP/source hosting, heroes are in server/users.db and the world in server/utils/map.json. Stop the server and back them up before updating.

      Is it free? Can I change it?

      Yes. It's open source under the MIT license. Host your own world, read the code, or contribute on GitHub. It's early access, so expect the odd bug.
