A co-op dungeon crawler for your terminal._

Up to four friends share one dungeon. Walk out of the safe room, fight your way down through six biomes, and climb from level 1 to 100. Free and open source. v0.4.0

Hall of heroes

#HeroClassLevelKills

How it works

  1. One person runs a server. On Windows that's a single .exe; on macOS and Linux it's a ZIP and Node.js. How to host
  2. Everyone downloads the client, picks Create a new hero, and enters the server's address. Heroes are saved on the server.
  3. Choose a class and walk out of the safe room. The further you go, the higher the monster level and the better the loot.

What's down there

%
Real co-op. Party members share the XP of every kill. If you fall near a friend you go down instead of dying, and they have 20 seconds to revive you.
G
Lair bosses that telegraph a ground slam, enrage at low health and get tougher for every hero they face. Everyone who fought gets their own loot.
/
Random gear in five rarities: Common, Magic, Rare, Epic and Legendary. The blacksmith upgrades items to +10.
Ω
Waystones to travel back down, and § lore scrolls that tell what woke up under Emberfall.
★
World events the whole server shares: Gold Rush, Blood Moon, Loot Frenzy, and treasure goblins that run off with your gold.
✦
Rebirth at level 100: start again with permanent bonuses. Bounties, combos and 32 achievements along the way.

Host a server

Windows

Download cdc-host-windows-amd64.exe and run it. It includes Node.js and the server, and asks how friends should connect:

  • Cloudflare: gives you an HTTPS address to share. No router setup. The address changes each time you restart.
  • Direct: an encrypted invite (with #key=…) for the client's Server field. Opens the game port and tries UPnP; some routers and CGNAT need Cloudflare instead.
  • Both, LAN (your network only) or Local (this computer only).

Saves live in %LOCALAPPDATA%/CoopDungeonHost/saves. Keep the tls folder next to it to keep your direct-invite identity. Press Enter in the host window to save and stop.

macOS and Linux

  1. Install Node.js LTS.
  2. Download and unzip cdc-server.zip somewhere permanent. Your world and heroes are stored in that folder.
  3. Start it from that folder (on Windows, double-click start-server.cmd):
$ sh start-server.sh

Then connect the client to localhost:3143, or open that address in a browser for one-line launch commands. Friends on your network use the address the server prints.

Questions

Can I play in a browser?

No, the game runs in a terminal. You can watch any server from a terminal with curl <server>/watch.

Can I play alone?

Yes. Run a server on your own computer and connect to it. Friends can join any time.

My friend can't connect.

localhost only works on the computer running the server. On the same network, use the LAN address the server prints. Over the internet, use the Windows host's Cloudflare or Direct mode, or a public host with the port open.

Where are my saves? How do I update?

Windows host: %LOCALAPPDATA%/CoopDungeonHost/saves. ZIP install: server/users.db (heroes) and server/utils/map.json (world). Stop the server and back them up, then replace the program files.

Is it free?

Yes, MIT licensed. It's early access, so expect bugs. Reports and pull requests are welcome on GitHub.
